# The Last Commit

> A cinematic frontend experience created for the Cherry Network WebDev Trainee Task.

## Overview

**The Last Commit** is a frontend concept built around the idea of a final commit — the moment where an idea becomes something real and worth leaving behind.

The website focuses on creating an immersive visual experience through large-scale typography, minimal interfaces, animated elements, interactive hover states, and scroll-based transitions.

## Design Direction

The visual direction combines three primary inspirations:

- **VEA (Virtually Ever After)** — experimental layouts, immersive composition, dark environments, thin framing, and interactive visual elements.
- **General Intelligence Company** — editorial typography, restrained UI, atmospheric presentation, and generous whitespace.
- **Apple iPhone Duo** — clean hierarchy, polished spacing, minimal controls, and product-style visual discipline.

These references were used as visual inspiration rather than directly reproduced.

## Sections

### 01 — Hero

Introduces **The Last Commit** through large typography, an animated central visual, and minimal technical metadata.

### 02 — The Idea

Introduces the central concept:

> What if this was your last commit?

### 03 — The Challenge

Breaks the challenge into three ideas:

- **BUILD**
- **BREAK**
- **COMMIT**

### 04 — The Timeline

Presents the journey from registration to the final submission.

### 05 — Final Commit

A final call-to-action encouraging participants to register and take part in the challenge.

## Getting Started

### Prerequisites

Make sure Node.js and npm are installed.

### Installation

Clone the repository and install the dependencies:

    npm install

### Run the development server

    npm run dev

The Vite development server will provide a local URL, usually:

    http://localhost:5173/

## Design & Development Approach

The project was developed with a visual-first approach.

The process was:

1. Study visual references.
2. Extract useful design principles rather than directly copying them.
3. Establish the visual direction.
4. Build the hero experience.
5. Create the remaining content sections.
6. Add animations and micro-interactions.
7. Add responsive behavior.
8. Refine spacing, typography, and interactions.
